# GitHub Copilot Instructions

## Project Overview
This project is a Flask-based Sudoku web application. Generate code that follows Python best practices and integrates cleanly with the existing project structure.

## Coding Standards
- Follow PEP 8 coding style.
- Use meaningful and descriptive variable and function names.
- Keep functions small and focused on a single responsibility.
- Avoid duplicate code by creating reusable functions whenever possible.

## Documentation
- Add comments only where the logic is not immediately obvious.
- Include docstrings for all new functions and classes.

## Error Handling
- Handle invalid inputs gracefully.
- Avoid crashing the application because of unexpected user input.
- Display clear and user-friendly error messages.

## Flask Best Practices
- Keep business logic separate from route handlers.
- Do not modify unrelated parts of the application.
- Preserve the existing project structure.

## Frontend Guidelines
- Maintain the current UI style.
- Use semantic HTML.
- Keep CSS organized and readable.
- Do not introduce unnecessary JavaScript libraries.

## Performance
- Write efficient and readable code.
- Avoid unnecessary loops or repeated calculations.

## Testing
- Ensure generated code runs without errors.
- Preserve existing functionality when adding new features.
